# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

**Unstable** releases (GitHub pre-releases: `-test`, `-rc`, etc.) are not listed
in this history.

## How to maintain this file

1. Record changes under **[Unreleased]** during development (Added, Changed,
   Deprecated, Removed, Fixed, Security).
2. When publishing a stable version via the **Release** workflow, rename
   `[Unreleased]` to `[X.Y.Z] - YYYY-MM-DD` and add a new empty `[Unreleased]`
   section.
3. Optional: copy the version body (excluding the **Install** section) into the
   GitHub release notes; install instructions are still generated by CI
   (`.github/workflows/release.yml`).

## [0.0.31] - 2026-09-29

### Fixed

- Schema migrations ignore the internal `doido-jobs` table, avoiding conflicts
  when introspecting or migrating the application database.

## [0.0.30] - 2026-09-22

### Added

- **i18n** layer in `doido-core`, with locales organized per crate and distinct
  keys for `pt` and `pt_BR`.
- Flag to migrate without exporting entities; boot adjustments for `doido-jobs`
  and `doido-storage`.
- Configurable logger at application startup.

### Changed

- Refactored **configuration** loading and layering.
- Locale behavior when a translation is missing (no aggressive normalization).
- Crate publish order on release.

### Fixed

- **Mailer**: SMTP addresses (`MAIL FROM`) and dot-stuffing in `DATA` per RFC.
- Global pool and row lifecycle in jobs/storage after updates.

### Security

- Updated `rustls` (RUSTSEC-2026-0285).

## [0.0.29] - 2026-09-01

### Added

- **`doido db schema diagram`**: HTML ER diagrams from the live database
  (`SchemaDesign`, introspection via sea-schema).
- In-process **`doido db migrate` / `seed`** from the app binary; built-in seeder
  wired to the migrations crate.
- Expanded test coverage (per-crate gate, boot exclusions) and e2e scenarios for
  schema diagram, routes, and jobs CLI.
- Tutorial/blog improvements (seed, profile and sign-out links when signed in).

### Changed

- Entity/model templates and model generator regex.
- Messages and flow for the migration update command.

## [0.0.28] - 2026-08-19

### Added

- **App-registrable generators** via the `Doido::register_generator` builder.
- Generator scaffold for custom generators.
- Richer backtrace/stack trace on errors.

### Changed

- E2e scenarios moved into `doido` crates.
- Recreate `schema.rs` when missing in the migration flow.

### Removed

- Experimental `doido-payments` crate.

## [0.0.27] - 2026-08-17

### Added

- Configurable **CORS** with stricter defaults and extended preflight support
  (including `Authorization` and `Content-Type`).

### Changed

- CORS e2e tests aligned with the new behavior.

## [0.0.26] - 2026-08-16

### Changed

- **Entity/model** templates and generated entity tests.

## [0.0.25] - 2026-08-16

### Added

- Full **chat** (Action Cable) and **auth** example apps.
- Conversation/group structure, `last_read_at`, and chat views.
- Fixes to **doido-cable** protocol deserialization.

## [0.0.24] - 2026-08-14

### Added

- **Devise-style** modules in `doido-auth`: `auth.modules` and module-aware install
  (validatable, trackable, lockable, timeoutable, recoverable, confirmable,
  rememberable).
- **Built-in auth controllers** by default; `auth:controllers` generator to
  eject and customize.

### Fixed

- Auth request body parsed by `Content-Type` (fixes JSON 500).
- `User` import when ejecting controllers; strengthened `auth_generators` e2e.

## [0.0.23] - 2026-08-14

### Added

- **Db seed** generators and flow; seed user and seed + auth tests.
- End-to-end tutorial/blog; model validation in e2e.

### Changed

- Post/model examples in the blog; release-e2e adjustments.

## [0.0.22] - 2026-08-10

### Added

- **`db/seed`** subproject and **schema push** e2e scenario.
- Updated validation tests; blog documentation.

## [0.0.20] - 2026-08-08

### Added

- **Helpers** generator and integration in scaffolds/controllers.
- Reorganized test harness; job migrations with revised column types.

### Changed

- **sea-orm** and dependency updates; controller/job macros.
- Generator tests moved to `doido-generators`; Makefile and coverage.

## [0.0.19] - 2026-08-05

### Added

- Initial migrations for **jobs** and **storage** structures; mailer container
  in the development environment.
- Toggle between **API** and **auth** modes when generating apps.

### Changed

- Shared target compilation across tests; audit options.

## [0.0.18] - 2026-08-04

### Added

- **`doido-auth`** crate (first publishable release): unified authentication.
- Dedicated test harness.

### Changed

- crates.io publish scheme; blog templates and documentation.
- Removed unsupported specific providers; `cargo-deny` adjustments.

## [0.0.17] - 2026-08-02

### Added

- **`cargo doido`** alias in Cargo configuration.

### Changed

- CI and documentation blog examples.

## [0.0.16] - 2026-08-01

### Added

- **`make release-e2e`** gate in the Makefile and release workflow.
- E2e scenarios: `new`, HTML/API scaffolds, migrations, model fields, cable,
  `storage:install`, smoke tests for remaining generators.
- Documentation site (blog) theme and layout.

### Fixed

- E2e app fork preserves the `db/migration` crate; warnings when generating code;
  migrations via CLI.

## [0.0.15] - 2026-08-01

### Added

- Framework **migration** trait so apps avoid importing `sea_orm_migration`
  directly.

## [0.0.14] - 2026-08-01

### Added

- Import conventions: **axum** only via `doido-controller`, **sea-orm** only via
  `doido-model`, templates via the `doido` module.

### Changed

- Development `docker-compose`; crate publish order.

## [0.0.13] - 2026-07-31

### Fixed

- CLI **`--version`** flag now reports the correct version.

### Changed

- Updated Dockerfile and Docker Compose.

## [0.0.12] - 2026-07-31

### Changed

- Refactored path references in generated templates; fmt/clippy.

## [0.0.11] - 2026-07-31

### Added

- Automated **release** pipeline (GitHub Releases + crates.io + binaries).
- **Blog/docs** deploy (GitHub Pages) and Dockerfile for the site.

### Changed

- Version in app templates; interactive flags on the `new` CLI.

## [0.0.10] - 2026-07-31

### Changed

- **Semver** realignment for published crates (same base commit as `0.1.0`; the
  `0.0.x` series adopted for subsequent releases).

## [0.1.0] - 2026-07-30

First stable public release of the Doido framework (Rust, Rails-style).

### Added

- Modular workspace: **core**, **controller** (routes + axum middleware), **model**
  (SeaORM), **view** (Tera), **config**, **generators/CLI**, **mailer**, **jobs**,
  **cache**, **cable**, **storage** (blobs, attachments, disk/memory/S3/R2/Azure
  backends).
- Rails-like generators (scaffold, model, migration, controller, etc.) with an
  extensible registry and automatic injection into `config/routes.rs`.
- CLI: `server`, `console`, `db`, `worker`, encrypted credentials, banner.
- Inflector, test helpers, spec documentation, and initial blog.
- **Rails 8–style** task integration, test coverage, and Markdown blog.

### Changed

- **clippy** hardening, `deny` warnings, and dependency auditing.
