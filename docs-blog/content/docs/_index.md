Welcome to the Doido manual. These pages are the authoritative, hand-written
reference for using the framework. They are curated on top of the framework's
design specifications — if you want the full design intent for a subsystem,
each guide links to the corresponding spec.

Start with **[Getting started](@/docs/getting-started.md)**, then browse the
guides in the sidebar.

> **Looking for the design specs?** The complete per-crate specifications live in
> the [`docs/` folder](https://github.com/doido-rs/doido/tree/master/docs) of the
> repository. They are the source of truth for design intent; this manual is the
> source of truth for day-to-day usage.
