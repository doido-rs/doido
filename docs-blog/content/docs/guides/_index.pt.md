Guias aprofundados e orientados a tarefas para os subsistemas do framework. Cada
guia é curado a partir da especificação de design correspondente na
[pasta `docs/`](https://github.com/doido-rs/doido/tree/master/docs); a
especificação é linkada no topo de cada guia.

Há um guia para cada módulo do framework — **Core**, **Configuração**, **Models**,
**Controllers & roteamento**, **Middleware & sessões**, **Views**, **Geradores & CLI**,
**Jobs**, **Mailer**, **Cache**, **Cable** e **Storage** — com uma introdução seguida de
uma seção por funcionalidade e um exemplo de código executável. Navegue por eles na barra
lateral.
