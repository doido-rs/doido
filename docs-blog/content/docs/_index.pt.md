O Doido é um framework web para Rust inspirado no Rails — com baterias inclusas e
async-native. Esta documentação leva você do primeiro `doido new` até publicar em
produção: models, controllers, jobs em background, mailers, websockets, storage e
a CLI que conecta tudo.
