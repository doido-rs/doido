Bem-vindo ao manual do Doido. Estas páginas são a referência oficial, escrita à
mão, para usar o framework. Elas são curadas a partir das especificações de
design — se você quiser a intenção completa de design de um subsistema, cada guia
aponta para a especificação correspondente.

Comece por **[Primeiros passos](@/docs/getting-started.pt.md)** e depois explore os
guias na barra lateral.

> **Procurando as especificações de design?** As especificações completas por
> crate ficam na [pasta `docs/`](https://github.com/doido-rs/doido/tree/master/docs)
> do repositório. Elas são a fonte da verdade para a intenção de design; este
> manual é a fonte da verdade para o uso no dia a dia.
