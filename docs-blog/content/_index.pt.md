# Construa rápido com Rust.

O **Doido** traz a produtividade do Rails — convenção sobre configuração, uma CLI
rica orientada a geradores e subsistemas com baterias inclusas — para uma stack
Rust async-native e fortemente tipada, construída sobre
[axum](https://github.com/tokio-rs/axum) e
[sea-orm](https://www.sea-ql.org/SeaORM/).

Roteamento, ORM, views, mailer, jobs, cache, websockets, storage e muito mais —
cada um vive no seu próprio crate e pode ser usado isoladamente. Este site é o
manual do framework e a casa das novidades do projeto.
