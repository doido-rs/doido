O Doido é construído sobre **convenção sobre configuração**.

Veja como trazemos a produtividade do Rails — geradores, subsistemas com baterias
inclusas e uma CLI rica — para uma stack Rust async-native construída sobre
[axum](https://github.com/tokio-rs/axum) e
[sea-orm](https://www.sea-ql.org/SeaORM/).
