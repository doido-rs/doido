Doido is built on **convention over configuration**.

See how we bring Rails productivity — generators, batteries-included subsystems,
and a rich CLI — to an async-native Rust stack built on
[axum](https://github.com/tokio-rs/axum) and
[sea-orm](https://www.sea-ql.org/SeaORM/).
