# Build fast with Rust.

**Doido** brings the productivity of Rails — convention over configuration, a
rich generator-driven CLI, and batteries-included subsystems — to an
async-native, strongly-typed Rust stack, built on
[axum](https://github.com/tokio-rs/axum) and
[sea-orm](https://www.sea-ql.org/SeaORM/).

Routing, ORM, views, mailer, jobs, cache, websockets, storage, and more — each
lives in its own crate and can be used on its own. This site is the framework's
manual and the home of project news.
